# Fundamentos de Python

Programas escritos durante mi formación en fundamentos de programación.
Cada archivo resuelve un problema concreto aplicando estructuras básicas:
recorrido de listas, condicionales, acumuladores y funciones.

## Contenido

| Archivo | Qué hace |
|---|---|
| `maximo.py` | Encuentra el mayor de una lista, con protección contra listas vacías |
| `contador.py` | Cuenta elementos usando un acumulador |
| `producto.py` | Multiplica todos los elementos de una lista |
| `decidir.py` | Decisión con `if` / `else` sobre un umbral |
| `bodega.py` | Control de temperaturas con dos acumuladores simultáneos |
| `pedidos.py` | Tres acumuladores: cantidad, suma y máximo |
| `funciones.py` | Funciones con uno y dos parámetros |
| `resumen.py` | Composición de funciones y guardia contra datos vacíos |
| `lotes.py` | Control de cadena de frío usando diccionarios |

## Contexto

Trabajo en bodega de distribución de reactivos de laboratorio, donde el control
de temperatura, lote y caducidad es parte del proceso diario. Varios de estos
programas modelan situaciones reales de ese trabajo.

## Cómo ejecutar

```
python lotes.py
```

Requiere Python 3.
